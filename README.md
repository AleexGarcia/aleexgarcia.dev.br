# 🪓 O Dev Viking — Portfólio Full Stack

> **Status do Projeto:** 🚀 Em Desenvolvimento / Planejamento

Uma fusão autêntica, satírica e de alto impacto visual entre a estética nórdica tradicional (guerreiro de barba cheia) e a engenharia de software moderna. Este projeto não é apenas um portfólio, mas uma prova real de conceitos avançados de arquitetura front-end, integrações serverless e performance de alto nível.

---

## 🛠️ Arsenal Tecnológico (Tech Stack)

*   **Front-end:** Next.js (App Router), TypeScript, Tailwind CSS (ou Chakra UI).
*   **Back-end (Serverless API):** Next.js API Routes (Vercel) ou AWS Lambda + API Gateway.
*   **Design Pattern:** Bento Grid Layout (Grade modular de alta conversão).
*   **Deploy & Hospedagem:** Vercel / AWS (Free Tier).

---

## 🗺️ Roadmap de Desenvolvimento (Etapas a Fazer)

O projeto foi dividido em **5 fases estratégicas** para garantir qualidade de código, design premium e custo zero de infraestrutura.

### 📅 Fase 1: Preparação de Assets & Boilerplate
- [ ] **Otimização do Avatar Viking:** Remover o fundo da ilustração oficial e convertê-la para o formato `.webp` de alta compressão (foco em performance no Lighthouse).
- [ ] **Setup do Projeto:** Inicializar o projeto Next.js com TypeScript, Tailwind CSS e estruturar as pastas (`/components`, `/assets`, `/api`).
- [ ] **Configuração do Tema:** Definir a paleta de cores *Tech Premium* no arquivo de configuração do Tailwind (`#0B0F19` para o fundo e `#161B26` para os cards).

### 📐 Fase 2: Construção da Dobra Principal (Bento Grid)
- [ ] **Grid Estrutural:** Codificar o container responsivo usando CSS Grid (1 coluna no mobile, 3 colunas no desktop).
- [ ] **Hero Card:** Implementar o bloco de apresentação com o nome, cargo, frase de efeito e o posicionamento do avatar viking.
- [ ] **Card Arsenal Técnico:** Adicionar os blocos das tecnologias com efeitos de *hover* e brilhos personalizados para cada logo (React, NestJS, AWS).
- [ ] **Card do Troféu:** Renderizar o bloco de destaque contendo o selo oficial da certificação *AWS Certified Cloud Practitioner*.
- [ ] **Card de Conectividade:** Embutir os botões de ação rápidos para GitHub, LinkedIn e download do currículo.

### 📂 Fase 3: Seção de Projetos & Back-end
- [ ] **Layout dos Cards de Projetos:** Criar um componente reutilizável para listar os projetos em ordem vertical, contendo mockups e tags coloridas.
- [ ] **Catálogo de Projetos Destaque:** Inserir os dados reais dos principais projetos (Gerenciador de Tarefas Avançado e Compass Events).
- [ ] **API Serverless Interna:** Configurar uma rota `/api/projects` ou microsserviço AWS Lambda para servir os dados dinamicamente, provando a integração Full Stack do site.

### 🎨 Fase 4: Lapidação de UI/UX & Sátira
- [ ] **Easter Eggs Temáticos:** Adicionar as métricas divertidas (ex: Contador de bugs decapitados, nível da barba).
- [ ] **Página 404 Personalizada:** Criar a tela de erro satírica ("Valhalla encontrou um erro 404. Esta página foi saqueada").
- [ ] **Otimização de Performance:** Garantir que todas as imagens possuam propriedades corretas de tamanho para evitar *Cumulative Layout Shift* (CLS).

### 🚀 Fase 5: Deploy & Validação Final
- [ ] **Testes de Responsividade:** Validar o comportamento do Bento Grid em múltiplos tamanhos de tela (Mobile, Tablet, Monitores ultrawide).
- [ ] **Deploy de Produção:** Conectar o repositório à Vercel para automação de CI/CD.
- [ ] **Auditoria Lighthouse:** Rodar a ferramenta do Google para garantir notas próximas a 100% em Performance, Acessibilidade e SEO.
