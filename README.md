## 🏗️ Architecture

The portfolio follows a modular, component-driven structure built around the Next.js App Router.

```text
src/
└── app/
    │
    ├── _constants/
    │   ├── contacts.ts
    │   ├── gridVariants.ts
    │   ├── projectsData.ts
    │   └── techs.ts
    │
    ├── components/
    │   ├── ui/
    │   │   ├── Badge.tsx
    │   │   ├── BrowserMockup.tsx
    │   │   ├── Button.tsx
    │   │   ├── Card.tsx
    │   │   ├── HeroCardViking.tsx
    │   │   ├── ProjectCard.tsx
    │   │   ├── TerminalMockup.tsx
    │   │   └── ...
    │   │
    │   ├── BentoGrid.tsx
    │   ├── Footer.tsx
    │   ├── Header.tsx
    │   └── Projects.tsx
    │
    ├── hooks/
    │   └── useBentoAnimations.ts
    │
    ├── globals.css
    ├── layout.tsx
    ├── not-found.tsx
    └── page.tsx
```

The main application is composed from reusable sections including the header, Bento Grid, projects area and footer.

## ✨ Interaction & Motion

The portfolio isn't intended to be a static page.

It uses animation as part of the experience while keeping interactions purposeful.

### GSAP

Used for:

* Scroll-triggered animations
* Cursor movement simulations
* Interactive UI elements
* Browser mockup animations
* Magnetic interactions
* Motion transitions

The browser mockup, for example, uses GSAP and ScrollTrigger to animate the simulated cursor and page scrolling when the component enters the viewport.

## 🧩 UI Philosophy

Every component is designed around three principles:

```text
        ┌──────────────┐
        │   FUNCTION   │
        └──────┬───────┘
               │
       ┌───────▼───────┐
       │   EXPERIENCE  │
       └───────┬───────┘
               │
       ┌───────▼───────┐
       │   PERFORMANCE │
       └───────────────┘
```

**Function first.**

The interface should communicate clearly and make navigation intuitive.

**Experience matters.**

Motion, visual hierarchy and micro-interactions should make the product memorable without becoming noise.

**Performance is part of the design.**

Animations, assets and components should be implemented with production performance in mind.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm

### Installation

```bash
git clone https://github.com/AleexGarcia/portfolio-pessoal.git

cd portfolio-pessoal

npm install
```

### Development

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

### Production

```bash
npm run build
npm run start
```
